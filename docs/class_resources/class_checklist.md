# Class Checklist

Use this list to pack for a name tag class.

## Per student

### Kit

- [ ] One kit of every item in the [BOM](../../pcbs/nametag_back/bom.csv), packaged per student
- [ ] 1 AA battery (not listed in the BOM)
- [ ] Physical assembly doc (printed copies of
      [the assembly guide](../../pcbs/nametag_back/assembly/assembly_guide.pdf))
- [ ] 1 pair of tweezers

## Shared class supplies

### Solder paste

- [ ] PCB stencil for the back board (`nametag_back`)
- [ ] 1 solder paste squeegee
- [ ] Solder paste
- [ ] Paper towels
- [ ] Isopropyl alcohol
- [ ] Gloves
- [ ] Extra PCBs for the solder paste jig (they hold the target board in
      place under the stencil)
- [ ] Tape for the jig and stencil
- [ ] Screwdriver for the M3 screws
- [ ] Supplies for adding a simple name: letter stickers, or another option
      from the README's "Adding your name" section
- [ ] Example completed name tags
